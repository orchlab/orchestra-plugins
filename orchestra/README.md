# Orchestra plugin

Connects ChatGPT, Codex, Claude and Claude Code to Orchestra's hosted MCP
server, `https://mcp.orch.so/mcp`, signed in with your Orchestra account. Each
app works in your workspaces as its own member, with your access.

```
claude plugin install orchestra --marketplace orchlab/orchestra-plugins
```

Installing it in each app, and the links: see the
[repository's README](https://github.com/orchlab/orchestra-plugins#readme).
